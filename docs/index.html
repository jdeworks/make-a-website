WebStarter Kit

A guided foundation for building websites. Tell your AI agent what you want to build, and it walks you through every step — from first idea to live deployment.

Get Started Read the Handbook

How It Works

1

Point your AI agent here

Give your AI agent (Claude Code, Cursor, Copilot) the link to the CLAUDE.md file. It reads the instructions and knows what to do.

2

Describe your idea

Tell the agent what you want to build. A portfolio? A blog? A small business site? It will ask the right questions.

3

Get a working site

The agent builds your project step by step — with tests, security basics, and deployment instructions baked in.

What You Get

Tested Code

Vitest is set up from the start. Your code has tests from day one.

Security Basics

Environment variables, input validation, and dependency auditing covered.

Professional README

A clear README is generated for your project, ready to share.

Deployment Ready

GitHub Pages for static sites, Railway for server apps. CI/CD included.

Good Design

Tailwind CSS with design guidance so your site looks polished, not generic.

Framework Flexibility

Start vanilla or pick React, Vue, or Astro. Upgrade later if you want.

Get Started

Option 1: Clone the repo

git clone https://github.com/yourusername/make-a-website.git
cd make-a-website

Then open it in your editor with an AI agent (Claude Code, Cursor, etc.) and say: "Help me build a website."

Option 2: Point your agent to CLAUDE.md

Copy this URL and paste it into your AI agent's chat:

https://raw.githubusercontent.com/yourusername/make-a-website/main/CLAUDE.md
